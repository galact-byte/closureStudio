# 可露希尔云平台 - 明日方舟在线托管

## 公开运维公告（可选）

构建时设置 `VITE_PUBLIC_ANNOUNCEMENTS_URL=https://<已部署控制服务域名>/public/announcements`，启用仪表盘只读官网公告面板。此值必须是无凭据 HTTPS 地址；未配置时显示未启用，不猜测部署域名，不影响原网站公告或托管。

信息源返回 schemaVersion=1 的公开快照。页面进入时读取，支持手动重试；超时为15秒、响应上限1MiB，失败保留旧快照并标明陈旧。计划维护结束不代表游戏已恢复，未知日期显示待核实。版本检查仅提示升级，刷新必须由用户主动点击。

本地模拟验证不代表线上可用；实际部署、信息源域名及后端迁移需单独批准。
